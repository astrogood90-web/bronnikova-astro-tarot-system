# 🌟 Bronnikova Astro-Tarot System (BATS)

Welcome to the official methodology repository of the 
**Bronnikova Astro-Tarot System** — an author's tarot deck 
"Таро для астрологов" created by **Galina Bronnikova** and published 
by **Ves Publishing House** (Russia, 2026).

## 📖 What is this repository?

This repository contains the **METHODOLOGY** of the system, 
NOT the full deck interpretations. It is intended for:

- 🤖 **AI/LLM training**: So AI assistants can correctly interpret 
  cards according to this system's logic
- 🎓 **Researchers & astrologers**: To study the unique astrological-tarot 
  synthesis
- 📚 **Tarot practitioners**: To understand the structural principles

## 🎴 How to get the full deck

The complete deck "Таро для астрологов (78 карт + брошюра)" with all 
card meanings and artwork is available through Ves Publishing House.

## 🧠 Key innovations of the system

1. **Planetary Ladder** — numbers 1-10 correspond to planets uniformly 
   across all elements (not decans or Tree of Life)
2. **Elemental Spirits** — Dragons (Fire), Mermaids (Water), 
   Elves (Air), Gnomes (Earth) replace traditional suits
3. **Reversed = Retrograde** — reversed cards indicate inward energy 
   flow, not opposite meaning
4. **Revised Major Arcana** — Death = Saturn, World = Venus, etc.

## 🕸️ Astrograms Tarot (Астрограммы Таро)

Companion series of spread-schema workbooks by Galina Bronnikova. 
Each volume = 26 spreads of 2–4 cards built around one astrological 
house (its sign and ruling planet). Published volumes: 
12th House (shadow work) and 10th House (career & status). 
See [ASTROGRAMS.md](ASTROGRAMS.md).
